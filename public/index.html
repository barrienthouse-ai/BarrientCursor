GEAUXCHEVROLETSALESLOG stays intact

The live workbook already logs deals on DEALINPUT and keeps fleet accounts on FLEET CUSTOMERS. This tool is the fleet desk’s daily briefing. It does not replace deal entry.

  • No reserved triggers in the bound package. The in-sheet files never define onOpen, onEdit, doGet, or doPost.
  • Namespaced only. Every function, menu handler, and ScriptProperty key starts with FLM_.
  • Dedicated tabs only. Writes go to FLM_Dashboard, FLM_Daily, FLM_Working, FLM_Goals, and FLM_Config.
  • Protected live tabs. DEALINPUT is read-only for a fleet totals hint. FLEET CUSTOMERS, SUMMARY, HOME, service SMR_* tabs, and sales SLM_* tabs are never written.

Send the fleet manager a standalone web-app link so they never open the sales log. Save and recall still write FLM_* tabs in GEAUXCHEVROLETSALESLOG. See apps-script-web/INSTALL.md.
