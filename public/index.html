GEAUXCHEVROLETSALESLOG stays intact

This is the same collision-safe pattern as Sales (SLM), Service (SMR), and Fleet (FLM). Parts tickets already in the workbook stay operational — this tool is the daily GM briefing, not a replacement for CDK or PARTS_TICKETS.

  • No reserved triggers. This project never defines onOpen, onEdit, doGet, or doPost.
  • Namespaced only. Every function, menu handler, and ScriptProperty key starts with PMR_.
  • Dedicated tabs only. Writes go to PMR_Dashboard, PMR_Daily, PMR_LostSales, PMR_Sop, PMR_Backorders, PMR_Cores, and PMR_Config.
  • Protected live tabs. PARTS_ITEMS, PARTS_TICKETS, SVC_PARTS_REQUESTS, SERVICE BOARD, SUMMARY, HOME, and existing SLM_ / SMR_ / FLM_ tabs are read-only to PMR.

In Apps Script, add PMR_onOpen(); to your existing onOpen, then run PMR_install(). Optional: send the parts manager the standalone web-app URL so they never open the sales log.
