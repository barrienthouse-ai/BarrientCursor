GEAUXCHEVROLETSALESLOG stays intact

The live workbook already logs deals on DEALINPUT and rolls MTD on SUMMARY. This tool is the daily briefing log sales managers complete at close. It does not replace deal entry.

  • No reserved triggers. This project never defines onOpen, onEdit, doGet, or doPost.
  • Namespaced only. Every function, menu handler, and ScriptProperty key starts with SLM_.
  • Dedicated tabs only. Writes go to SLM_Dashboard, SLM_Daily, and SLM_Config.
  • Protected live tabs. DEALINPUT is read-only for a retail totals hint. SUMMARY, HOME, LOGDEAL, service SMR_* tabs, and AutoCrat are never written.

In Apps Script, add SLM_onOpen(); to your existing onOpen, then run SLM_install().
