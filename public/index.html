Will not interfere with current sheet tools

The Google Sheet you shared is private, so this environment cannot read the live Apps Script project. The installer is written so it does not need that access to stay safe:

  • No reserved triggers. This project never defines onOpen, onEdit, doGet, or doPost.
  • Namespaced only. Every function, menu handler, and ScriptProperty key starts with SMR_.
  • Dedicated tabs only. Writes go to SMR_Dashboard, SMR_TechHours, SMR_Gross, SMR_HeatCases, SMR_RepairOrders, SMR_Roster, and SMR_Config.
  • Existing sheets stay put. Install never deletes, hides, or renames a tab that is not an SMR tab.

In your current workbook, add one line to the existing onOpen function: SMR_onOpen();. Then run SMR_install() once. If you share the sheet as “Anyone with the link can view,” a follow-up pass can map your current script names against this namespace.
