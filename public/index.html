GEAUXCHEVROLETSALESLOG stays intact

The live workbook is readable. It already has 69 tabs, including a weekly SERVICE BOARD and hidden SVC_RO / SVC_RO_LINES tables. Apps Script source is not in a Sheet export, so install still avoids reserved trigger names.

  • No reserved triggers. This project never defines onOpen, onEdit, doGet, or doPost.
  • Namespaced only. Every function, menu handler, and ScriptProperty key starts with SMR_.
  • Dedicated tabs only. Writes go to SMR_Dashboard, SMR_TechHours, SMR_Gross, SMR_HeatCases, SMR_RepairOrders, SMR_Roster, and SMR_Config.
  • Protected live tabs. SERVICE BOARD, SVC_RO, SUMMARY, HOME, parts/accounting JSON tabs, and AutoCrat are read-only to SMR.

In Apps Script, add SMR_onOpen(); to your existing onOpen, then run SMR_install(). Optional: SMR_importRosterFromServiceBoard() copies the shop nicknames into SMR_Roster only.
